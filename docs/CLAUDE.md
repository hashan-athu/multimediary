# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm start                # dev server at http://localhost:3002/docs/
npm run build            # production build (must pass before committing)
npm run typecheck        # TypeScript type check
npm run clear            # clear Docusaurus cache

# API reference (run these after editing api/openapi.yaml)
npm run clean-api-docs   # delete all generated files in docs/api-reference/
npm run gen-api-docs     # regenerate from api/openapi.yaml
```

Always run `npm run build` after any structural change to confirm there are no broken links or build errors.

## Architecture

### Two content areas

**Guide** (`docs/docs/guide/`) — 10 hand-written Markdown pages. Listed explicitly in `sidebars.ts` under `guideSidebar`. Edit these directly.

**API Reference** (`docs/docs/api-reference/`) — generated by `docusaurus-plugin-openapi-docs` from `api/openapi.yaml`. Never edit these files manually; they are regenerated and overwritten. The source of truth is `api/openapi.yaml`.

### Key config decisions

- `routeBasePath: "/"` — docs are served directly at `baseUrl` (`/docs/`), not at `/docs/docs/`. A doc with ID `guide/introduction` resolves to `/docs/guide/introduction`.
- `baseUrl: "/docs/"` — the entire site is mounted at `/docs/` (intended for reverse-proxy deployment alongside the Rails API).
- `categoryLinkSource` is intentionally **absent** from the plugin's `sidebarOptions`. Using `"tag"` or `"info"` causes a `useCurrentSidebarCategory()` build error in Docusaurus v3 with this plugin version. Without it, Docusaurus uses `generated-index` pages for categories, which works correctly.
- Blog is disabled (`blog: false`).

### OpenAPI spec

`api/openapi.yaml` is the single source of truth for the API reference. It covers every endpoint under `/api/v1` (admin + public) using OpenAPI 3.0.3. After editing it:

1. `npm run clean-api-docs`
2. `npm run gen-api-docs`
3. `npm run build` to verify

The generated `docs/api-reference/sidebar.ts` is imported by Docusaurus automatically via the `autogenerated` entry in `sidebars.ts`.

### Sidebar wiring

`sidebars.ts` defines two sidebars:
- `guideSidebar` — explicit list of all 10 guide doc IDs
- `apiSidebar` — `autogenerated` from the `api-reference/` directory (picks up the generated `sidebar.ts`)

Both are wired into the navbar via `type: "docSidebar"` items in `docusaurus.config.ts`.

### Homepage

`src/pages/index.tsx` is a plain React page (no `HomepageFeatures` component). It links to `/docs/guide/introduction` and `/docs/api-reference/multimediary-api`. These paths must remain valid after any structural changes.
