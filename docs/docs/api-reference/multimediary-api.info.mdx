REST API for the Multimediary physical media library management system.

All admin endpoints require a JWT bearer token obtained from `POST /api/v1/admin/login`.
Public endpoints require no authentication.

## Rate limiting

- Login endpoint: 5 requests per minute per IP
- All `/api/*` endpoints: 300 requests per minute per IP

Exceeding the limit returns `429 Too Many Requests`.
